# UI 重设计调研：happyclaw 对照 + trellis 玩具感诊断（2026-09-28）

证据来源：happyclaw 上游 cef72b28（`/tmp/happyclaw-latest/web`）、trellis main@274b2a6、实机截图 `/tmp/ui-research/shots/{trellis,happyclaw}/`（happyclaw 登录后的页面未拍到：会话表为空，需要用户提供登录方式）。

## 一句话结论

trellis 的「玩具感」不在信息架构（侧栏方案 A、Console IA 已落地且不动），而在**视觉语言**：高饱和 indigo 加三色渐变 logo、298 处 emoji 充当图标、对话里每一轮都套一张卡、同屏 ≥5 种饱和色，外加原语层残缺。happyclaw 显得成熟，靠的是**克制**（语义 token、描边代替阴影、统一 h-8 密度、单一强调色）和**运行态可信度**（run 快照恢复、滚动防抖、排队消息）。它自己的毛玻璃登录页和 emoji 能力卡恰恰是反例，不照搬。好消息：trellis 的 token 架构（oklch + 多皮肤）已就位，大部分根因靠「改变量值 + 补原语 + 换图标」就能解决，不需要推倒重写。

## 根因排序（trellis）

| # | 根因 | 实测 | 修法 |
|---|---|---|---|
| 1 | 配色是 Tailwind 默认脸 | 主色 indigo-600（chroma 0.262）；logo 是 indigo→fuchsia→amber 渐变；语义色相撞：未读=成功（emerald），分叉=警告（amber），Project 模式=危险（rose） | 重建 token 取值：主色降饱和，四对撞色拆开，类名不变 |
| 2 | emoji 代替图标 | 298 处 / 72 个文件；⚡ 一个符号表示三种意思；设置导航 9 个 emoji；工具行首 📄🔍🌐 | 引入 lucide 并建 `Icon` 原语；emoji 只留给用户内容 |
| 3 | 原语层残缺 | 裸 `<button>` 283 个（原语只占 33%）；圆角 token 采用率 18%；没有 Input、Select、Tabs、Tooltip、Confirm 原语；原生 confirm 15 处 | 引入 Radix / shadcn 式原语 + 扩守卫测试 |
| 4 | 对话流过度装饰 | 每轮一张带阴影的卡 + 英文 "Turn" + 圆形「你」头像；流式时 4 种指示同时出现；卡片套了三层边框（截图 d-02） | 改为无框连续流：用户消息用浅灰块，助手消息全宽正文，流式状态只留一种 |
| 5 | 强调色泛滥、层级平 | Header 约 12 个控件同权重；同屏 ≥5 种饱和色 | Header 分三组：导航 / 会话语境 / 系统；状态信息改用中性色 |
| 6 | 反馈体系分裂 | 4 套 toast（两套叠在同一坐标）；5 种加载写法；直接展示 `e.message` 约 62 处 | 统一 Toast 队列、Skeleton、ConfirmDialog、错误卡 |
| 7 | 文案里的实现词 | YOLO、trigram、root、pane、transcript、Turn；中英混杂 | 建术语表后统一改一遍 |
| 8 | 魔法数 | 方括号值 205 处、内联 style 65 处、`active:scale-95` 28 处 | 建 size / motion token；守卫测试扩到 hex、方括号值、style |
| 9 | 设置页不像同一个产品 | 宽度有 612 / 770 / 900 三种；没有 404 / error 页；深色模式下画布节点仍是浅色 | 统一 PageShell 骨架；补 `not-found.tsx` / `error.tsx` |

另有实机发现的 bug：模型下拉被树浮窗盖住，是 z-index 问题（截图 d-14）。

## 从 happyclaw 借什么

**视觉 / 外壳**
- 语义 token 三层结构：`@theme` 映射 → `:root` → `.dark`；控件统一 h-8、rounded-lg、text-sm。
- 用 `ring-1 ring-foreground/10` 描边代替阴影；弹层动效只用 100ms 淡入 + zoom-95。
- 暖灰底 + 单一强调色；字体用 DM Sans，中文回退系统字体。
- 管理页固定骨架：PageHeader（副标题放实时计数，右侧依次是「刷新」和主操作）+ 四态分支（skeleton / error / empty / list）。
- Badge 带语义 variant；确认文案写清后果；有回收站。
- 连接状态用 toast 提示，不做常驻横幅；主题用内联脚本防闪屏；照顾 reduced-motion。

**对话**
- run 生命周期以事件为准，断线重连后用快照恢复，另有孤立等待态回收。
- 贴底判断只看真实滚动事件；流式内容按 rAF 合并；平滑滚动加锁。
- 运行中追加的消息进入排队区，可以排队、打断当前回复（steer）、编辑、调序。
- Thinking、工具卡、子 agent 卡：运行时展开，结束后自动折叠，但尊重用户手动操作。
- 发送、停止、加载三态合一的主按钮；输入法组字保护；草稿按会话保存；发送失败保留输入；显示「发送到：X」。
- 异常分级：权限拒绝单独出红色横幅，常规工具调用收进折叠区。
- Markdown 按内容特征懒加载重型渲染管线。

**不借**
- 毛玻璃 / 极光风格的营销登录页。
- 三套配色。
- emoji 能力卡。
- 颜色语义过载（思考、task、spawn、工具各占一种色）。
- 流式时是卡片、完成后是正文的风格不一致。
- 工具轨迹在回复完成后就消失：这是 trellis 的差异化，工具轨迹必须持久保留。
- 没有 Cmd+K：trellis 的键盘层应该超过它。

## 不能动的东西

- 任务 `interrupted` 显示为灰色（`app/settings/tasks/page.tsx:673-690`）。
- TreePanel 的小浮窗 + 小点形态（9/9 两次否决）；只修 z-index。
- 离线 Herdr 会话按已归档处理（9/16）。
- AS 控件块的动线卡语言与 DOM 钩子（9/15）。
- 审批卡按钮权重：「允许一次」为主按钮，「总是允许」降级。
- 手机端 44px 热区与 `data-mobile-*` 钩子：`scripts/mobile-verify` 依赖它们。
- 设置页用整页硬导航。
- `IconButton` 的 label 必填。
- 15 条快捷键与 KeyboardHelp。
- 品牌渐变不随皮肤变化：这是原有的刻意裁决，若新方向要改，需用户重新拍板。
