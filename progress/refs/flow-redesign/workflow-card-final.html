对齐要点 · 请确认这 8 条产品决定

  1. 挂载点 ：卡片直接长在时间线里那条 Workflow tool 行上，默认可见，不需要 /workflow ，也不加卡片外框和阴影
  2. 折叠规则 ：运行中保持展开并实时刷新；结束后自动收成一行摘要（名称 · 状态 · agents · 用时 · token），点一下展开。表头本身就是摘要，只有一套结构
  3. agent 行字段 ：状态字形、label、模型短名、最近一个工具、用时、token，attempt >1 时加重试标记；点一下 agent 行 展开元信息面板（阶段、模型、尝试、状态、排队 / 开始 / 最近活动时刻、耗时、token、工具调用、最近工具），B 卡里的行有完整示例数据；v1 不给 prompt / 结果 / 命令预览
  4. 窄屏取舍 ：≤560px 隐藏模型短名和最近工具，保证每个 agent 仍是一行；表头数字整体换到第二行
  5. 50+ agent ：超过 8 个 agent 的阶段自动分栏，16 个 agent 占 8 行；分栏后仍超过 12 行时，尾部连续的安静行折进可反复展开收起的「… 还有 n 个」；运行中和已失败的行永不被折叠
  6. 旧 daemon 兜底 ：退化成一条普通 tool 行，并补一句「daemon 版本较旧，暂无阶段明细」，不留空壳卡片
  7. killed 的中文 ：当前写「已终止」；若要和 Run 列表完全一致可改成「已取消」
  8. 不在范围内 ：单个 agent 的暂停 / 停止、远程 workflow、prompt 与结果预览、脚本正文，以及「只看活跃」这类额外筛选

A · 时间线上下文 卡片活在普通 tool 行之间：同样的行高、同样的折叠箭头、同样的左侧缩进轨。它比一条普通 tool 行高，但没有外框、没有阴影，不会盖过对话本身
